# Quiz — Projeto de Desenvolvimento de Dashboard Analítico

Quiz interativo de revisão da disciplina (UniSales, 2026/2), em uma única página HTML.

- **UAs do 2º bimestre** (14 questões): padrões cognitivos, introdução à visualização de dados, análise de negócios em BI, Power BI e visualização de gráficos.
- **Revisão da última prova** (12 questões): tipos de variável, média, mediana, desvio médio, distribuição de frequências, DW/ETL e tipos de dado.

Abra o `index.html` no navegador ou acesse pelo GitHub Pages.
